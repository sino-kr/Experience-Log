# Experience-Log
직무 경험 기록 및 역량 관리 웹페이지

## 구현 내역
- **1단계:** 경험 기록 페이지 기본 레이아웃 및 탭 구조 구성
- **2단계:** 경험 꺼내기 기능 및 직무 매칭 버튼 활성화 구현
- **3단계:** 기록 작성 템플릿 및 Fuse.js 기반 기록 목록 검색 추가
- **4단계:** 캘린더·스트릭 시각화(FullCalendar, Cal-Heatmap, D3.js) 및 Lucide 아이콘 적용
- **최종 정리:** 누락된 세부 기능 및 원본 UI 스타일 전체 반영

## 사용 오픈소스
- **Lucide Icons:** UI 아이콘 표시
- **Fuse.js:** 오타 허용(퍼지) 검색
- **FullCalendar:** 월간 캘린더 뷰 및 날짜별 기록 표시
- **Cal-Heatmap:** 활동 잔디(스트릭) 시각화
- **D3.js:** Cal-Heatmap 데이터 시각화 지원
